# -R6-
Rainbow Six Siege — Zapret Game Filter Небольшая утилита для Windows, которая запускает выбранный профиль Zapret при работе Rainbow Six Siege или Ubisoft Connect и останавливает фильтрацию после закрытия игры. Предназначена для устранения проблем с сетевым подключением и поиском матчей.
ИНСТРУКЦИЯ
1. Скачайте архив из файлов.
2. Распакуйте его на рабочий стол.
3. Запуск: дважды нажмите Start-R6-Zapret.cmd.
4. Windows запросит права администратора — они нужны WinDivert для перехвата пакетов.
5. Выберите режим: UDP (начните с него), TCP+UDP или TCP. Если режим не поможет, повторно запустите файл и выберите другой.
