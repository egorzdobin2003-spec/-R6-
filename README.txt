R6 ZAPRET — ВРЕМЕННЫЙ GAME FILTER ДЛЯ RAINBOW SIX SIEGE

Запуск: дважды нажмите Start-R6-Zapret.cmd.
Windows запросит права администратора — они нужны WinDivert для перехвата пакетов.
Выберите режим: UDP (начните с него), TCP+UDP или TCP. Если режим не поможет, повторно запустите файл и выберите другой.

Что делает программа:
- ждёт Ubisoft Connect или Rainbow Six Siege;
- включает стратегию Game Filter для портов 1024–65535;
- выключает winws, когда целевые процессы завершены;
- завершает winws при закрытии окна наблюдателя или Ctrl+C;
- не устанавливает службу и не добавляет автозапуск Windows.

Ограничение области действия:
Game Filter ограничивает фильтр портами, но WinDivert не передаёт PID на сетевом уровне. Поэтому невозможно гарантировать воздействие только на процессы Ubisoft/Rainbow Six. Пока лаунчер или игра открыты, совпадающий TCP/UDP трафик других программ тоже может попасть под фильтр.

Конфликт:
Если уже работает другой winws.exe или драйвер WinDivert, этот запуск откажется стартовать. Сначала остановите текущий Zapret через его собственный интерфейс. Не закрывайте случайный процесс WinDivert вручную.

Стратегии:
Папка zapret-source содержит официальный комплект Flowseal 1.10.3 со стандартными стратегиями ALT и исходными BAT-файлами. Start-R6-Zapret.cmd запускает отдельный профиль Game Filter; стандартные general*.bat этим профилем не запускаются.
